Research portfolio

Programs built around real operating constraints.

Our active projects span agent reliability, clinical language systems, energy forecasting and evaluation infrastructure. The program records below are fixed summaries maintained for this demonstration site.

Active NS-AR-024

Aurora Reasoning Engine

Aurora studies how tool-using AI agents can plan inspection and maintenance work for industrial robotics while preserving an auditable record of every observation, action and retry.

Start date
March 14, 2024
Project lead
Dr. Elena Marquez
Research hub
Paris
Current phase
Field validation

The current prototype coordinates a planner, a visual inspection model and a maintenance knowledge base. The team is measuring recovery from missing sensor readings and interrupted tool calls across three robot cells.

Active NS-HL-019

Meridian Health NLP

Meridian develops clinician-facing summaries that connect every generated statement to the exact section of a patient record from which it was derived.

Start date
July 22, 2023
Project lead
Dr. Priya Shah
Research hub
Toronto
Current phase
Prospective study

The study focuses on discharge summaries for cardiology teams. Human reviewers score factual coverage, source alignment and whether missing information is clearly communicated rather than inferred.

Active NS-EG-031

Atlas Grid Forecasting

Atlas combines weather ensembles and grid telemetry to forecast short-term renewable generation for regional electricity operators.

Start date
January 8, 2025
Project lead
Marcus Lee
Research hub
London
Current phase
Model calibration

Forecasts are produced in 15-minute intervals for a six-hour horizon. Operators receive uncertainty bands and a comparison against the previous production forecast before choosing whether to act on an update.

Active NS-EV-027

Lumen Evaluation Suite

Lumen is a reproducible evaluation toolkit for multi-step AI workflows, covering evidence collection, tool failures and structured handoffs.

Start date
October 3, 2024
Project lead
Camille Durand
Research hub
Paris
Current phase
Internal release

Each Lumen run records the task, model configuration, intermediate evidence and final output. The first internal release supports web research and operations-assistant workflows with deterministic replay fixtures.
